# 🐍 Python Basic Projects

Welcome to my collection of beginner-level Python projects!  
These mini-projects were created during my early learning phase to practice core Python concepts like variables, loops, functions, conditionals, and basic object-oriented programming.

## 📁 Projects Included

### 🎯 Guess the Number  
A simple number guessing game where the computer selects a number and the player tries to guess it with hints.

### 🏠 Rent Calculator  
Calculates the total house rent including extra charges. Great for basic arithmetic and input/output practice.

### 🍽️ Restaurant Bill Generator  
Simulates a restaurant billing system where users input menu items, and the program calculates the total bill with tax.

### 🐍💧🔫 Snake Water Gun Game  
A console-based game (like Rock-Paper-Scissors) using Snake, Water, and Gun as the choices.

### ❌⭕ Tic Tac Toe  
A two-player console game where players take turns marking a 3x3 grid until someone wins or the game ends in a draw.

### 🏦 Basic Banking System  
An object-oriented banking program with account creation, debit, credit, and balance-check functionality.
